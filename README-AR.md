كاتب موهوم للنشر الرقمي — نسخة GitHub Pages
محتويات المشروع
index.html: بنية الصفحة الرئيسية بالعربية.
style.css: التصميم الأسود والذهبي والتوافق مع الموبايل.
script.js: قائمة الموبايل، البحث والتصنيف، نبذات الكتب، وتجارب واجهة الحساب والتعليقات.
تشغيله على موبايل أندرويد
أنشئ حسابًا على GitHub أو سجّل الدخول.
أنشئ مستودعًا جديدًا (Repository) باسم katib-mawhom.
ارفع الملفات الثلاثة index.html وstyle.css وscript.js إلى جذر المستودع، ويمكنك رفع هذا الملف أيضًا.
افتح صفحة المستودع ثم Settings → Pages.
في Build and deployment اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واضغط Save.
انتظر اكتمال النشر، وسيظهر رابط الموقع في قسم Pages، عادةً بالشكل https://USERNAME.github.io/katib-mawhom/.
تعديلات ضرورية قبل الإطلاق
في index.html غيّر your-email@example.com إلى بريد تملكه لاستقبال استفسارات النشر.
استبدل الكتب والخواطر التجريبية بأعمال تملك حقوق استخدامها.
اختبر الموقع من رابط GitHub Pages بعد النشر.
حدود النسخة الحالية — مهم
GitHub Pages يستضيف ملفات الواجهة الأمامية فقط. تسجيل الدخول هنا تجريبي ولا ينشئ حسابات. التعليقات تُحفظ في localStorage على جهاز المتصفح نفسه ولا تظهر للزوار الآخرين. لا توجد لوحة إدارة فعلية أو دفع أو بيع في هذه النسخة.
لإضافة حسابات وتعليقات عامة وإدارة محتوى ومبيعات بشكل حقيقي، اربط لاحقًا خدمة خلفية وقاعدة بيانات ومصادقة (مثل Supabase أو Firebase) وخدمة دفع مناسبة لبلدك. لا تضع مفاتيح سرية أو كلمات مرور في ملفات JavaScript العامة.
